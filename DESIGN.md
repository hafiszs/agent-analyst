# Design Direction: Agent Analyst (Vultr Blast Radius Zero)

Reading this as: Data Analysis Workspace and Sandbox Monitor for data analysts and engineers, in a Calm Architectural Editorial style, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

## Dials
- **ENERGY**: 1 (Calm, focused, utilitarian luxury, zero loud AI glows or harsh neon accents)
- **RHYTHM**: 2 (Balanced, functional layout with clear content-driven sections)
- **MOTION**: 1 (Subtle, purposeful micro-transitions, tab shifts, live pulse on active container execution)

## Palette (Architectural Slate & Warm Amber Accent)
- **Dark Theme (Default for technical workspace)**:
  - Base Background: `#090d16` (Deep slate night)
  - Card / Panel Surface: `#111726` (Refined elevation)
  - Secondary Surface / Muted: `#172033` (Subtle inset)
  - Structural Borders: `#1f2c44` (Clean hairline)
  - Primary Text: `#f1f5f9` (High contrast crisp white-slate, WCAG AA compliant)
  - Secondary / Muted Text: `#94a3b8` (Clean slate, 5.2:1 contrast)
  - Deliberate Accent: `#f59e0b` (Warm amber, used strictly for execution focus and key actions)
  - Containment / Shield Accent: `#10b981` (Emerald green for zero-leak / safe sandbox status)
  - Alert / Limit Hit Accent: `#f43f5e` (Rose red for sandbox containment events)
- **Light Theme**:
  - Base Background: `#f8fafc` (Warm alabaster)
  - Card / Panel Surface: `#ffffff` (Pure crisp white)
  - Secondary Surface / Muted: `#f1f5f9` (Subtle off-white)
  - Structural Borders: `#e2e8f0` (Soft slate border)
  - Primary Text: `#0f172a` (Deep ink slate)
  - Secondary / Muted Text: `#64748b` (Neutral graphite)
  - Deliberate Accent: `#d97706` (Deep amber)

## Typography
- Primary Sans: `Plus Jakarta Sans`, system-ui fallback (clean, balanced, professional)
- Monospace: `JetBrains Mono`, `ui-monospace`, monospace (for Docker container IDs, Python scripts, metrics, and terminal logs)

## Iconography & Motifs
- Domain-relevant SVG and Lucide icons: Shield (sandbox isolation), Terminal (live stdout), Activity (CPU/RAM telemetry), FileSpreadsheet (datasets), BarChart3 (visualizations), CheckCircle2 (verified citations).
- Zero generic sparkle, magic wand, or robot icons.
- One deliberate focal point per view: Sandbox Lifecycle & Evidence verification.
